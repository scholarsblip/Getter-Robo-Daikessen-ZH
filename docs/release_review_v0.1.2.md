- 构建器读取原盘并写新目录，拒绝覆盖已有输出目录；限定字符串跨度，拒绝截断，已完成读回和原始未改扇区比较。中断的开发构建仍可能留下无最终清单的中间镜像，不能据文件存在就交付。面向用户的补丁助手 README 已说明 `.partial`、源哈希和目标哈希校验。
- README 建议将“1885 条剧情文本”改为“1885 类剧情/战斗/资源内名称文本，共 29964 处；963 处核心字段”，避免类别和唯一计数混淆。开发镜像 README 中“过长文本保留原文”是通用策略，本版实际超长跳过为 0。
