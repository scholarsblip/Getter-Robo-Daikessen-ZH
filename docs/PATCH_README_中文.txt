《盖塔机器人大决战！》简体中文实验补丁

本说明用于 v0.1.2 简体中文实验差分补丁包；源码仓库本身不含补丁文件、原盘或完整汉化镜像。补丁文件名、输入及输出校验值以补丁包内 patch_manifest.json 为准。

如本地交付文件夹内已有同名 BIN 和 CUE，可直接在模拟器中打开 CUE，无需再次打补丁。可分享的 Patch.zip 仅包含差分补丁和说明，不含原盘；Source.zip 是翻译文本、工具和重建说明。

需要准备

1. Python 3.9 或更新版本。
2. xdelta3，可放在 apply_getter_patch.py 同目录、系统 PATH，或用 --xdelta 指定路径。仅使用适合自己操作系统的可信版本。
3. 自行准备的日版原始 BIN，或只含一个 BIN 的 ZIP。

支持的原盘：SLPS-02232《ゲッターロボ大決戦！》
BIN 大小：663111120 字节
SHA256：08f189c914fa753af0ba690579712636f1d8b21eb7777c89b6fc10041c725807

不同版本、已修改镜像、重新打包造成内容变化的镜像无法使用。补丁包不包含游戏镜像；应用补丁不需要 BIOS、模拟器或联网。

使用方法

将 apply_getter_patch.py、patch_manifest.json 和清单指定的补丁文件放在同一目录。输出位置需要支持硬链接，例如 APFS、HFS+、NTFS 或常见 Linux 文件系统；FAT/exFAT 不适合作为本助手的输出位置。

macOS / Linux：
python3 apply_getter_patch.py "/路径/日版原盘.bin" --output "/路径/盖塔大决战_简中.bin" --xdelta "/路径/xdelta3"

Windows：
py -3 apply_getter_patch.py "D:\游戏\日版原盘.bin" --output "D:\游戏\盖塔大决战_简中.bin" --xdelta "D:\工具\xdelta3.exe"

输入也可以换成 ZIP 路径。程序只读取其中唯一的 BIN，不会按压缩包路径批量解压。ZIP 输入须额外预留约 633 MiB 临时空间；另需预留输出镜像所需空间。

程序先校验原盘和补丁，再生成 .partial 临时输出；目标 SHA256 验证通过后，才以不覆盖现有文件的方式生成最终 BIN 和单轨 MODE2/2352 CUE。原盘保持不变。请在模拟器中打开生成的 CUE。若目标 BIN、CUE 或对应 .partial 已存在，程序会拒绝覆盖，请另选文件名。中断或失败会清理本次临时 BIN；异常断电留下的 .partial 请确认后自行移走。

汉化范围与限制

已处理提取到的 1885 类剧情、战斗及资源内名称文本，共 29964 处，以及 963 处核心字段。以机器翻译为基础，补充人名、机体名、武器名、界面及超长句的定向审核和精简，未完成逐句人工校对。部分暂未确认的人名仍保留日文拼写。

结构检查已通过：有效文本没有缺失或超出原始字段预算，修改后的资源可完整读回，修改光盘扇区的 EDC/ECC 通过校验。补丁助手还原后的完整镜像 SHA256 与测试版一致。使用 SwanStation 软件渲染、解释器模式和 OpenBIOS，从最终版冷启动进入中文剧情及首场战斗地图；能力表、地图、武器和存档等菜单已检查。通过正常操作触发学校过场及敌方攻击演出，中文机体名、攻击/防御文字和 HP 变化可见，战斗后正常返回地图。具体记录见 QA_记录.json。

过场影片、片中字幕和部分图片形式的界面文字尚未汉化。实测战斗中的伤害字样“ダメージ”及默认自定义角色姓名“アキラ”仍为日文。姓名输入字符表仍保留原假名；隐藏角色口令等参与游戏判断的原始字符串予以保留。全部路线、战斗情境及后期关卡尚未完成测试，可能仍有误译、排版、字形或兼容性问题。本版为实验补丁，不是全流程验证的正式汉化版。

反馈时请提供：补丁版本、清单中的目标 SHA256、模拟器及版本、出现问题的章节/操作步骤，并尽量附截图。请勿随反馈上传游戏原盘或 BIOS。

补丁应用助手不会向外发送任何文件，不会修改输入镜像。最终版本和校验值只以补丁清单及实际生成后的验证结果为准。

字体说明

12×12 字格使用 Cubic11 原生像素字形，另有六个字形取自文泉驿 12px 点阵：啧、氩、稣、颚、飓、—。保留主文字颜色；汉字未实现原游戏的全部渐变阴影。字体来源和许可见“字体许可”及 Source.zip。游戏原始内容的权利属于各权利人。
