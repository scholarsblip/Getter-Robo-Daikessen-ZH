# 《盖塔机器人大决战！》简中术语表

目标版本：PS1 原版 **SLPS-02232**。术语表位于 `work/glossary/canonical_zh.json`，可运行 `tools/build_glossary.py` 重建。共 **150 项**，包括本作角色、机体与合体形态、武器、驾驶员能力、组织，以及少量待原盘确认的界面用语约定。

这份文件是独立整理的术语依据，尚不是全剧情译文，也不表示游戏原盘已提取出这些字段。后续须用实际解出的文本确认出现位置、编码、指针和控制码。没有采用其他游戏补丁的译文或字库。

- **已见授权简中用法**：流龙马、神隼人、巴武藏、早乙女达人等参考 [Bilibili 授权作品页](https://www.bilibili.com/bangumi/media/md2352/)；黑盖塔、真盖塔龙、车弁庆、盖塔皇帝、盖塔射线、闪光烈阳弹等参考[联动公告一](https://www.taptap.cn/moment/750110259372099156)及[公告二](https://www.taptap.cn/moment/760247527227263278)。引用的是命名习惯，不是其他游戏的技能效果或机制。
- **通行译名、汉字简化、项目翻译、临时译名**在 `status` 中分开标记。文件名 `canonical_zh.json` 不代表每项均有官方中文定名。每项都列出登场及译名来源，未找到中文来源时明确列为空。
- `exact_field_map` 只供**已识别为完整实体字段**的精确匹配使用，不适用于英文或日文子串全局替换。`alternatives` 用于人工核对，不自动加入匹配表。临时译名、编号冲突和未确认出现的 UI 字段排除在自动表外。

## 本作必须保留的差别

1. **原创主角与斩小队**：アキラ／ケイ是可改名主角，暂用“阿基拉／凯”作候选。不能把ケイ自动改成早乙女溪或南风溪。原创女驾驶员为水樹茜／秋山椿／柴崎楓，简化为**水树茜／秋山椿／柴崎枫**。
2. **一文字号、橘翔、大道剴**：一文字號统一为一文字号。大道的日文原字是**剴**，规范简化为**剀**；旧中文资料常用“凯”。词表保留“大道剀／大道凯”和“盖塔剀／盖塔凯”的选择，暂不自动替换；详见[日文名依据](https://srw.wiki.cre.jp/wiki/大道剴)和[旧中文用法](https://bbs.newwise.com/thread-382800-1-1.html)。
3. **男爵**：本作角色是ラセツ男爵，译为“罗刹男爵”，不能照搬其他版本的伯爵称号。
4. **黑盖塔与真盖塔龙**：本作黑盖塔是备用零件拼成的原创混合机；真盖塔龙是人型最终阶段机。不能据 OVA 印象修改设定或一律把真盖塔龙缩成“真龙”。
5. **驾驶员能力**：本作使用「能力」，没有普通机战作品完整的精神指令、改造、强化零件和气力系统。隼人的“2回移動”译作**二次移动**，该回合不能攻击，不能误写成二次行动；一文字号“復活”是自己复活；水树茜“収集”提高盖塔动力单位的自动 EN 回复；柴崎枫“交換”是与友军交换位置。
6. **武器行为**：盖塔幻影在本作属于武器，不能套用其他机战作品的被动分身技能。盖塔射线通常是直线地图攻击；大雪山崩落与武藏／弁庆的驾驶条件相关。译名修改不得改变这些原有条件。
7. **编号与能量字段**：保留 `BT-23`、`α04`、`T520`、`007`、`H24`、`80000`、`HP`、`EN`、`GE`。GE 与 EN 不能混为一项。
